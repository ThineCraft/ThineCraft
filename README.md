# ThineCraft

Website: [thinecraft.io](https://thinecraft.io)

ThineCraft is the planned umbrella project for shared direction, coordination, and discovery across the ThineCraft family.

The current core project set includes [CloudCraft](https://github.com/ThineCraft/CloudCraft), the planned Rust-based distributed control plane for self-hosted workloads, open-source applications, backups, and disaster recovery.
